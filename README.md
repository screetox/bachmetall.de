The official website of Bach Metall featuring contact and service information.

## 📝 About

**bachmetall.de** is the official online hub for Bach Metall — a place to find contact information, project examples, and more ways to connect.

## 📂 Features

- ☎️ **Contact Information** – Quick access to phone number, email, and more
- 🔩 **Service Overview** – Detailed information about the services provided by Bach Metall
- 🖼️ **Past Projects** – Highlights and content of projects by Bach Metall

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/screetox/bachmetall.de.git
   ```
2. Open the [`index.html`](/index.html) file in a web browser.
